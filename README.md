# 🚀 CIFAR-10 AI Image Classifier using CNN

A Deep Learning based image classification system built with **TensorFlow**, **Keras**, and **Streamlit**.
This project uses a custom **Convolutional Neural Network (CNN)** trained on the **CIFAR-10 dataset** to classify images into 10 categories with an interactive GUI-based application.

---

## 📌 Features

✅ Custom CNN Architecture
✅ Data Augmentation
✅ Batch Normalization
✅ Dropout Regularization
✅ Real-Time Image Prediction
✅ Confidence Score Visualization
✅ Streamlit GUI Dashboard
✅ Modern Responsive UI
✅ CIFAR-10 Multi-Class Classification

